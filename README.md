# 🍞 面包浏览器 (Bread Explorer Homepage)

> “在信息的汪洋中，为你烤制一份最纯粹的导航面包。”

“面包浏览器”不仅仅是一个简单的个人网址导航站，而是一个集成了**沉浸式视觉体验、云端账号生态、虚拟经济系统**与**高性能视觉特效**的综合性 Web 个人数字空间。

### 🌟 项目愿景与开发理念
本项目诞生于对“极致轻量”与“高度定制化”的追求。我们抛弃了沉重的前端框架（如 Vue、React），完全采用**原生 HTML5 + CSS3 + 纯 JavaScript (ES6+)** 构建。这种极客式的开发方式，不仅保证了网页在任何设备上的“秒开”体验，更赋予了开发者对每一行代码、每一次动画帧的绝对控制权。

### 🛠️ 技术架构演进
项目最初采用纯前端架构，依靠浏览器的 `LocalStorage` 进行本地数据存储。在 `v1.4.0` 版本中，我们深度接入了 Supabase 云数据库，实现了“云端关系型三表分离”。
而在最新的 `v1.5.0` 版本中，我们完成了**史诗级的底层安全重构**：
1. **零信任 RPC 架构**：彻底封死前端直改资产的通道，所有积分、VIP 特权、兑换码核销全部交由云端 PostgreSQL 函数（RPC）处理，做到前端“只提交申请，不修改账本”。
2. **全自动化引擎**：引入 Supabase `pg_cron` 定时任务，实现废码自动清理、每日 VIP 积分发放、注册里程碑福利的无人值守全自动运转。
3. **实时双向同步**：接入 WebSocket 实时推送，打破传统轮询限制，实现云端数据变动（新邮件、积分发放）的秒级无感同步。

### 🎨 视觉与交互体验
- **沉浸式特效**：自研基于 Canvas 的高性能粒子引擎，支持落樱缤纷、心花怒放、并蒂双生等多种形态的烟花绽放，搭配屏幕抖动、红包雨等即时反馈动效，带来极致的视觉冲击。
- **全量主题定制**：内置涵盖日间/夜间模式下的多套精美主题（如花语秘境、暗黑黄金、赛博朋克等），配合独立开发的双向隔离字体系统（支持本地读取与网页上传），让每一位用户都能打造专属的视觉空间。
- **现代化 UI 交互**：采用毛玻璃（Glassmorphism）质感卡片设计，配合拖拽排序的“面包篮”组件，实现优雅流畅的页面交互体验。

## 📂 项目结构
- `index.html`: 主页面
- `assets/fonts/`: 存放本地内置的中英文字体
- `css/`: 样式表（变量、基础、布局、弹窗、特效、字体）
- `js/`: 脚本模块（核心、配置、UI、登录、主题字体、站点、邮件、积分、红包雨、开发者、初始化、烟花引擎、版本更新检测）

## ✨ 核心功能
1. **多主题与视觉特效**：内置多套精美主题，自带基于 Canvas 的高性能烟花引擎（支持各类定制烟花爆炸效果）与动态红包雨互动。
2. **字体深度定制**：中英文字体双向隔离加载，支持系统内置读取与网页端自定义上传，告别全局字体冲突。
3. **全云端安全生态**：基于 Supabase Auth 官方认证与 RLS 行级安全策略，支持跨设备安全登录、资产加密存储与云端持久化。
4. **开发者极客面板**：内置需要多重密钥与 UUID 强校验的三端代码执行器（前端 JS / 后端 SQL / 全栈），配备 15 次本机免密通行证。
