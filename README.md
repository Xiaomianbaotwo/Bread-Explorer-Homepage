# 🍞 面包浏览器 (Bread Explorer Homepage)

> “在信息的汪洋中，为你烤制一份最纯粹的导航面包。”

“面包浏览器”不仅仅是一个简单的个人网址导航站，而是一个集成了**沉浸式视觉体验、云端账号生态、虚拟经济系统**与**高性能视觉特效**的综合性 Web 个人数字空间。

### 🌟 项目愿景与开发理念
本项目诞生于对“极致轻量”与“高度定制化”的追求。我们抛弃了沉重的前端框架（如 Vue、React），完全采用**原生 HTML5 + CSS3 + 纯 JavaScript (ES6+)** 构建。这种极客式的开发方式，不仅保证了网页在任何设备上的“秒开”体验，更赋予了开发者对每一行代码、每一次动画帧的绝对控制权。

### 🛠️ 技术架构演进
项目最初采用纯前端架构，依靠浏览器的 `LocalStorage` 进行本地数据存储。在 `v1.4.0` 版本中，我们深度接入了 Supabase 云数据库，实现了“云端关系型三表分离”。
在 `v1.5.0` 版本中，我们完成了底层安全重构。而在这个史诗级的 `v1.5.99` 版本中，我们**突破了单机沙盒，正式开启了全云端社交生态的内测**：
1. **零信任 RPC 架构**：彻底封死前端直改资产的通道，无论是购买主题、好友转账、甚至发送建议，全部交由云端 PostgreSQL 函数（RPC）处理，做到前端“只提交申请，不修改账本”。
2. **全自动化引擎**：引入 Supabase `pg_cron` 定时任务，实现废码自动清理、每日 VIP 积分发放、注册里程碑福利的无人值守全自动运转。
3. **高并发实时社交**：接入 WebSocket 高级监听，不仅支持资产变更的秒级同步，更能实现好友聊天的实时收发、礼物的全屏拆包动画，毫无延迟。

### 🎨 视觉与交互体验
- **沉浸式特效**：自研基于 Canvas 的高性能粒子引擎，支持落樱缤纷、心花怒放、并蒂双生等多种形态的烟花绽放，搭配屏幕抖动、红包雨等即时反馈动效，带来极致的视觉冲击。
- **全量主题定制**：内置涵盖日间/夜间模式下的多套精美主题（如花语秘境、暗黑黄金、赛博朋克等），配合独立开发的双向隔离字体系统（支持本地读取与网页上传），让每一位用户都能打造专属的视觉空间。
- **现代化 UI 交互**：采用毛玻璃（Glassmorphism）质感卡片设计，配合拖拽排序的“面包篮”组件，实现优雅流畅的页面交互体验。

## 📂 项目结构
- `index.html`: 主页面
- `assets/fonts/`: 存放本地内置的中英文字体
- `css/`: 样式表（包含变量、基础、布局、弹窗、特效、字体、好友专属样式等）
- `js/`: 核心脚本模块（核心引擎、配置、UI、登录、主题、邮件、积分、红包雨、开发者、烟花、更新检测）
- `js/friend-system/`: **独立社交模块**（包含好友核心 `01-friends-core.js`、聊天 `02-friends-chat.js`、送礼 `03-friends-gift.js`）

## ✨ 核心功能
1. **多主题与视觉特效**：内置多套精美主题，自带基于 Canvas 的高性能烟花引擎与动态红包雨互动。
2. **字体深度定制**：中英文字体双向隔离加载，支持系统内置读取与网页端自定义上传。
3. **全云端安全生态**：基于 Supabase Auth 官方认证与 RLS 行级安全策略，支持跨设备安全登录、资产加密存储。
4. **极客开发者面板**：内置需要多重密钥与 UUID 强校验的三端代码执行器（前端 JS / 后端 SQL / 全栈），配备 15 次本机免密通行证。
5. **好友与社交系统 (Alpha 测试中)**：支持通过用户名搜索添加好友，实时收发文字消息，支持聊天记录本地清空与消息 15 分钟内撤回。
6. **云端礼物与盲盒 (Alpha 测试中)**：支持给好友赠送积分、主题或兑换码，以精美的“礼盒”形式展示，包含震撼的全屏拆包动画。


> ### ⚠️ **特别注意事项：**
> 本次更新中的【好友系统】与【聊天送礼系统】属于临时加急开发的重磅功能，底层逻辑庞大且复杂。由于开发时间非常仓促，当前版本（Alpha 测试版）中**极有可能存在各种未知的 Bug 或体验不畅的地方**。
> 如果在使用过程中遇到报错、消息不同步、礼包无法拆开等异常情况，请您多多包涵！并非常欢迎您通过主页左上角的【📮建议箱】直接向开发者反馈，我们会火速修复！
