# 🍞 面包浏览器 (Bread Explorer Homepage)

> “在信息的汪洋中，为你烤制一份最纯粹的导航面包。”

“面包浏览器”不仅仅是一个简单的个人网址导航站，而是一个集成了**沉浸式视觉体验、云端账号生态、虚拟经济系统**与**高性能视觉特效**的综合性 Web 个人数字空间。

### 🌟 项目愿景与开发理念
本项目诞生于对“极致轻量”与“高度定制化”的追求。我们抛弃了沉重的前端框架（如 Vue、React），完全采用**原生 HTML5 + CSS3 + 纯 JavaScript (ES6+)** 构建。这种极客式的开发方式，不仅保证了网页在任何设备上的“秒开”体验，更赋予了开发者（也就是你）对每一行代码、每一次动画帧的绝对控制权。

### 🛠️ 技术架构演进
项目最初采用纯前端架构，依靠浏览器的 `LocalStorage` 进行本地数据存储。随着功能的不断丰富与用户需求的升级，我们在最新的 `v1.3.2-Alpha` 版本中**深度接入了 Supabase (PostgreSQL) 云数据库**。
通过前端原生 `fetch` API 与云端 RESTful 接口的无缝对接，我们实现了一套“本地优先，云端异步双写”的混合数据流架构。这不仅保留了前端操作的丝滑流畅，更彻底打破了单机限制，实现了跨设备、跨浏览器的数据永久同步与持久化存储。

### 🎨 视觉与交互体验
- **沉浸式特效**：自研基于 Canvas 的高性能粒子引擎，支持落樱缤纷、心花怒放、并蒂双生等多种形态的烟花绽放，搭配屏幕抖动、红包雨等即时反馈动效，带来极致的视觉冲击。
- **全量主题定制**：内置涵盖日间/夜间模式下的多套精美主题（如花语秘境、暗黑黄金、赛博朋克等），配合独立开发的双向隔离字体系统（支持本地读取与网页上传），让每一位用户都能打造专属的视觉空间。
- **现代化 UI 交互**：采用毛玻璃（Glassmorphism）质感卡片设计，配合拖拽排序的“面包篮”组件，实现优雅流畅的页面交互体验。

## 📂 项目结构
- `index.html`: 主页面
- `assets/fonts/`: 存放本地内置的中英文字体
- `css/`: 样式表（变量、基础、布局、弹窗、特效、字体）
- `js/`: 脚本模块（核心、配置、UI、登录、主题字体、站点、邮件、积分、红包雨、开发者、初始化、烟花引擎）

## ✨ 核心功能
1. **多主题与视觉特效**：内置多套精美主题，自带基于 Canvas 的高性能烟花引擎（支持各类定制烟花爆炸效果）与动态红包雨互动。
2. **字体深度定制**：中英文字体双向隔离加载，支持系统内置读取与网页端自定义上传，告别全局字体冲突。
3. **全云端账号生态**：底层深度接入 Supabase 数据库，支持跨设备、跨浏览器的账号安全登录、积分实时同步、VIP 状态及邮件附件的云端持久化存储。
4. **安全与性能并重**：采用“本地优先，云端异步双写”策略，配合数据库行级安全策略（RLS），在保障前端丝滑交互体验的同时，确保云端数据的安全可靠。

## 🚀 v1.3.3-Alpha 新版本更新内容

### 🆕 功能新增
1. 全新接入 Supabase 云数据库（PostgreSQL），面包浏览器正式从“本地单机版”跨越至“云端网络版”。
2. 实现用户账号、密码、积分、VIP状态、邮件等核心数据的跨浏览器、跨设备永久云端存储与同步。
3. 开放全新的独立 API 密钥体系（Publishable Key），为未来多网页（如文章欣赏页）的数据互通打下坚实底座。
4. 删除了v1.3.2-Alpha版本加入的".assetsignore"文件

### 🔄 功能升级
1. 升级底层存储引擎（`01-core.js`），采用“本地优先，云端异步双写”策略，在保证页面读写速度的同时完成云端数据备份。
2. 优化应用启动流程（`11-init.js`），网页加载瞬间自动从云端拉取最新账本覆盖本地，确保多端数据 100% 一致。

### 🎨 界面美化
界面视觉保持原样，暂无样式调整。

### ⚡ 性能优化
1. 利用 Supabase 原生 RESTful API 进行无感同步，不影响前端交互帧率。
2. 云端请求加入异常捕获与容错处理，即使断网或接口超时，也能回退使用本地数据，保证网页不崩溃。

### 🛠️ BUG修复
1. 彻底修复了此前“在 A 浏览器注册账号，在 B 浏览器无法登录”的致命架构级限制。

### 🔒 安全修复
1. 数据库开启 RLS（行级安全策略），并严格区分“前端发布密钥”与“后端秘密密钥”，极大提升云端数据的安全性。

### ♻️ 代码重构
1. 重构了核心 `store` 对象，将原本单一的 `localStorage` 读写逻辑，优雅地剥离并注入了 `fetch` 异步云同步逻辑。

### 📦 依赖更新
本版本无新增第三方依赖，完全使用原生 Fetch API。

### 🧹 代码清理
暂无清理项。

### 🚧 已知问题
1. 目前仅核心用户信息（账号、积分等）实现了云同步，站点的“面包篮”收藏、搜索历史等边缘数据仍暂存本地（将在后续版本实现全量云端化）。
2. 受网络波动影响，极少数情况下云端拉取会有几秒钟延迟。
