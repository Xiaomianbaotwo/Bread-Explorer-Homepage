# 🍞 面包浏览器 (Bread Explorer Homepage)

一个基于纯前端（原生 HTML + CSS + JavaScript）开发的个人沉浸式导航主页。

## 📂 项目结构
- `index.html`: 主页面
- `assets/fonts/`: 存放本地内置的中英文字体
- `css/`: 样式表（变量、基础、布局、弹窗、特效、字体）
- `js/`: 脚本模块（核心、配置、UI、登录、主题字体、站点、邮件、积分、红包雨、开发者、初始化、烟花引擎）

## ✨ 核心功能
1. **多主题与特效**：支持多套主题切换，自带 Canvas 烟花引擎（含新春豪华特效）和红包雨。
2. **本地字体与自定义**：中英文字体双向隔离加载，支持内置读取和网页端上传。
3. **账号与积分**：本地 LocalStorage 存储的账号系统，包含积分、VIP 等虚拟经济。
4. **开发者面板**：内置一个隐藏的调试面板。

## ⚠️ 特别说明（重要）

### 1. 关于“开发者面板”的安全性
本项目是一个**纯前端、无后端**的个人玩具项目。
- **数据隔离**：所有账号数据均存在于浏览器的 `localStorage` 中，仅限本机使用。
- **关于执行代码（XSS 担忧）**：开发者面板中的“执行自定义代码”功能，是作者为了方便自己调试而故意留下的后门。在纯前端架构下，就算执行了恶意代码，也最多只能破坏使用者自己当前浏览器的页面状态，**不存在服务器层面的安全漏洞**。
- **适用场景**：本项目仅供个人使用或打包发给朋友娱乐，无需担心此面板带来的安全风险。如果是商业级企业项目，请务必删除该功能并引入真实后端。
