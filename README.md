# 🍞 面包浏览器 (Bread Explorer Homepage)

一个基于纯前端（原生 HTML + CSS + JavaScript）开发的个人沉浸式导航主页。

## 📂 项目结构
- `index.html`: 主页面
- `assets/fonts/`: 存放本地内置的中英文字体
- `css/`: 样式表（变量、基础、布局、弹窗、特效、字体）
- `js/`: 脚本模块（核心、配置、UI、登录、主题字体、站点、邮件、积分、红包雨、开发者、初始化、烟花引擎）

## ✨ 核心功能
1. **多主题与特效**：支持多套主题切换，自带 Canvas 烟花引擎（含新春豪华特效）和红包雨。
2. **本地字体与自定义**：中英文字体双向隔离加载，支持内置读取和网页端上传。
3. **账号与积分**：本地 LocalStorage 存储的账号系统，包含积分、VIP 等虚拟经济。
